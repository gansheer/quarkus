= Apache Camel on Quarkus
include::_attributes.adoc[]
:categories: integration
:summary: Entry point for everything Apache Camel on Quarkus.
:topics: camel,integration

https://camel.apache.org/[Apache Camel] is the Swiss knife of integrating heterogeneous systems with more than a decade
of history and a lively community of users and developers.

https://camel.apache.org/camel-quarkus/[Camel Quarkus] runs Camel inside your Quarkus application as naturally as any other CDI bean: same `application.properties`, same `quarkus dev`, same native compilation support.
With https://camel.apache.org/components/[400+ connectors], Camel covers databases, cloud services, messaging systems, SaaS APIs, and protocols from FTP to AS2.

* https://camel.apache.org/camel-quarkus/user-guide/first-steps.html[First Steps] -- create a Camel Quarkus application from scratch
* xref:camel-extend-quarkus.adoc[Extending Your Quarkus Application with Apache Camel] -- add Camel to an existing Quarkus application
